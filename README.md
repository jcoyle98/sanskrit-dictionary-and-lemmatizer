# Sanskrit Dictionary and Lemmatizer

A Logeion-style Sanskrit reference that runs entirely as a static site:

- **Dictionaries**: all 45 Cologne Digital Sanskrit Dictionaries (≈1.5 million entries), shown one at a time from a dictionary bar (or all together), with every entry linked to its scanned page at Cologne.
- **Lemmatizer**: type an inflected form (`gacCati`, `devAnAm`) and get every analysis (root or stem, case or person/number/tense) from [vidyut-kosha](https://github.com/ambuda-org/vidyut). A word that is not a headword opens its lemmas' entries automatically.
- **Paradigms with derivations**: conjugation and declension tables generated by vidyut-prakriya from the Aṣṭādhyāyī. Click any form to see its derivation, with the sūtra (and its text) applied at each step.
- **Etymology**: cognates in Greek, Latin, Gothic, Old English, Lithuanian, Avestan and other languages, plus loans (Greek astronomical terms, Persian and Arabic words, Prakrit back-formations), extracted from the dictionaries themselves. Every item carries the dictionary's own wording, entry number and printed page, and the page notes where several dictionaries agree.
- **Corpus**: lemma frequencies by text and by DCS time slot from Oliver Hellwig's Digital Corpus of Sanskrit.

Type SLP1 in the search box and it turns into Devanagari as you go, as on the Cologne site. Script (Devanagari/IAST), input scheme, and which dictionaries are shown and in what order are saved in the browser.

## Running it locally

Requirements: Python 3.9+, Rust with the `wasm32-unknown-unknown` target, [wasm-pack](https://rustwasm.github.io/wasm-pack/), git, curl.

```sh
git clone --recurse-submodules https://github.com/jcoyle98/sanskrit-dictionary-and-lemmatizer.git
cd sanskrit-dictionary-and-lemmatizer
make          # fetch sources (~1 GB), build the WebAssembly engine and the data index
make serve    # http://127.0.0.1:8765
```

Individual steps: `make fetch`, `make wasm`, `make dicts`, `make etym`, `make grammar`, `make kosha`, `make corpus`.

## Deploying

`.github/workflows/pages.yml` builds everything on GitHub Actions and publishes `site/` to GitHub Pages (Settings → Pages → Source: GitHub Actions). No server or database is needed: the dictionaries are split into small gzipped JSON shards fetched by headword, and the lemmatizer runs in the browser as WebAssembly. The lemmatizer data (≈30 MB compressed) is downloaded once and kept in the browser's Cache Storage.

## How it is built

| Path | What it does |
|---|---|
| `scripts/fetch_cdsl.py` | Downloads each dictionary's XML from its Cologne download page into `data-src/cdsl/<code>/` and makes the files read-only. Also fetches Cologne's etymology tables from csl-orig. |
| `scripts/build_dicts.py` | Reads each XML file (read-only) and writes `site/data/{sa,en}/` shards keyed by headword, storing every entry line exactly as published. Bibliographic data and the rights statement come from each dictionary's header. |
| `scripts/build_etym.py` | Extracts comparative material: language labels (“Gk.”, “lat.”, “goth.”, “Zd.”…), the words after them, Greek-script words, loan statements (“fr. Gk.”, “aus”, “borrowed from”), Cologne's root tables, and Grassmann's Ṛgveda references. |
| `scripts/build_grammar.py` | Rule texts (Aṣṭādhyāyī, vārttikas, Dhātupāṭha, Uṇādipāṭha…) from vidyut's data release, for the derivation tables. |
| `scripts/build_corpus.py` | Lemma counts per text and per `dcsTimeSlot` from the DCS CoNLL-U files. |
| `wasm/` | A small Rust crate exposing vidyut-kosha, vidyut-prakriya and vidyut-lipi to JavaScript. `wasm/patches/kosha-from-bytes.patch` adds a constructor so the kosha can load from memory (browsers have no filesystem). |
| `vendor/vidyut` | Vidyut, as a git submodule. |
| `site/` | The web app: plain ES modules, no build step. |

## Caveats

- The etymological material reflects the dictionaries' authors, mostly nineteenth-century. The extraction is pattern-based and can misread prose, which is why each item shows the original wording and a link to the page.
- The lemmatizer covers forms generated from the Dhātupāṭha and vidyut's stem lists; compounds, rare words and many Vedic forms are missing.
- DCS time slots are shown by number. The DCS data does not attach dates to them, so none are given.
